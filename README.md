## 🚀 Sobre mí

Soy un Desarrollador de Software enfocado en crear soluciones tecnológicas eficientes, escalables y centradas en el usuario. Mi experiencia abarca desde el desarrollo de aplicaciones web fullstack hasta la automatización de procesos mediante scripts y arquitecturas de bases de datos robustas. Me apasiona transformar problemas complejos en soluciones técnicas claras y elegantes.

He trabajado en proyectos que van desde sistemas de gestión farmacéutica y plataformas inteligentes con IA (OCR), hasta arquitecturas de E-commerce de alto nivel para artistas y sistemas administrativos locales portables. Mi objetivo principal es seguir creciendo profesionalmente mientras aporto valor real a través del código limpio y el alto rendimiento.
